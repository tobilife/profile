# 정상기

거대한 레거시를 이해하고, 오래가는 구조로 바꿉니다.

2009년부터 손해보험 3사에서 기간계와 비대면 채널을 개발하고 운영해 왔습니다.
요즘은 사이드 프로젝트로 AI 에이전트 하네스를 만들고 있습니다.

**https://tobilife.github.io/profile/**

## 경력

| 기간 | 회사 | 주요 업무 |
|---|---|---|
| 2022.09 ~ 현재 | 한화손해보험 비대면채널(CM) | 산출지원센터 TM 신규 시스템 구축, 자동차 TM 유지보수, 자동차보험 리뉴얼, 장기보험 고도화, 원데이 자동차보험 |
| 2017.12 ~ 2022.09 | 현대해상 비대면채널(CM) | 제휴 간편설계 시스템, 장기보험 신상품 개발, CM 청약 시스템 |

메리츠화재 재직 중 2012년 운영 최우수상, 2013년 매뉴얼 최우수상을 받았습니다.

## 기술

- **Backend** Java, Spring Framework, Spring Boot
- **Frontend** xPlatform, NCRM, JSP, jQuery, React, Vue, Next.js
- **Database** Oracle, DB2
- **Integration** EAI, Anylink, Cruzlink, RESTful API
- **AI** AI 에이전트 하네스 구축, AI 오케스트레이션, RAG, LangChain, Ollama, ChromaDB
